# Security Policy

This repository contains the public LightBaker web/client layer.

Do not open a public issue for a suspected security vulnerability, especially one involving scene uploads, artifact URLs, authentication, API authorization, storage, CORS, or backend job isolation.

Use GitHub's private vulnerability-reporting flow when available. Otherwise contact the maintainer through the GitHub profile to establish a private reporting channel.

Include:

- affected commit/version;
- impact and attack scenario;
- reproduction steps;
- browser/runtime context;
- whether the issue affects only this client or also the hosted API.

The private baking backend is maintained separately from this public repository.
